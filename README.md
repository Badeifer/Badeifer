### Badeifer

Plug-and-play widgets for the Corsair Xeneon Edge, plugins for Stream Deck and tools for Obsidian.

**Projects, previews and setup guides: [badeifer.github.io](https://badeifer.github.io)**

| | What | Where |
|---|---|---|
| Xeneon Edge | Claude usage, NVIDIA Deck, Needs You and Agent Home widgets for iCUE | [Widgets](https://badeifer.github.io/#edge) |
| Obsidian | Agent Keep, Pixel Keep and Task Pet: the Keep family | [Obsidian](https://badeifer.github.io/#obsidian) |
| Stream Deck | Plugins and icon packs, in development | [Stream Deck](https://badeifer.github.io/#streamdeck) |
| Claude Code | Session HQ: usage, repos and handoffs beside the chat | [Mods](https://badeifer.github.io/#claude) |

Questions or bugs: open an issue. Support development: [badeifer.github.io/#support](https://badeifer.github.io/#support).
